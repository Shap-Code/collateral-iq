# 00 - Start here

**Time:** 15 minutes
**You will learn:** what this repository is, and how to get it running
**You will need:** a computer, a GitHub account, and a GitHub Copilot licence

## What you are looking at

Collateral IQ is a small, working business-intelligence tool for residential
collateral valuation. It takes a subject property, screens a pool of closed
sales, adjusts them, and reconciles an indicated value. Then it rolls the whole
portfolio up into a dashboard that flags which files a reviewer should open first.

Nothing here is a real property. The data is synthetic and generated by a script.

The point of the repository is not the tool. The point is that it is a realistic
piece of our own domain that you can safely break, so that when you learn what a
Copilot *skill* is, you learn it on comps and adjustments rather than on a
to-do list app.

## Why the code is deliberately plain

- **No installs.** Standard-library Python only. No pip, no pandas, no npm. If
  your laptop has Python 3.10 or newer, you can run everything in this repo.
- **No build step.** The dashboard is one HTML file.
- **Small files.** You can read any file here in one sitting.

There are also three deliberate problems planted in the code: one real bug, one
missing test, and one piece of lazy math. You will find them in later lessons.
They are marked `TODO(lesson-NN)` so you can grep for them if you get stuck.

## Get it running

Open a terminal in the repository folder.

```bash
python --version                        # need 3.10 or newer
python -m unittest discover -s tests    # should end with OK
```

If `python` is not found, try `python3`. On Windows, try `py`.

Now set the path so Python can find the code, then run it:

```bash
# macOS / Linux
export PYTHONPATH=src
# Windows PowerShell
$env:PYTHONPATH = "src"

python -m collateral_iq value SUBJ-001
python -m collateral_iq flags
python -m collateral_iq serve
```

The last one starts a small web server. Open <http://localhost:8000> and you
should see the dashboard. Ctrl+C stops it.

If you open the folder in VS Code, `.vscode/settings.json` sets `PYTHONPATH` for
you in the integrated terminal, so you can skip the export.

## One habit to start with

Copilot is confidently wrong about appraisal on a regular basis. It will invent
an adjustment rate, use "comp" to mean an active listing, and average three
numbers that should never have been averaged. Every lesson here assumes you
check the output. The parts of this repository that make Copilot *less* wrong -
the instructions, the skills, the agents - exist precisely because the default
behaviour is not good enough for our work.
